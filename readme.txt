Drag and drop form builder for WordPress. Create beautiful, responsive forms with ease.

== Description ==

Dragwyb Form Builder is a powerful, flexible, and intuitive drag & drop form builder plugin for WordPress. It allows you to create custom forms easily without any coding knowledge. Build simple contact forms, complex surveys, and everything in between simply by dragging and dropping fields into your form.

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/dragwyb-form-builder` directory, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' screen in WordPress.
3. Navigate to the Dragwyb Form Builder menu in your WordPress dashboard to start creating your forms.

== Frequently Asked Questions ==

= Is this plugin free to use? =

Yes, the core features of the Dragwyb Form Builder are free to use.

= Do I need to know how to code to create forms? =

No! Dragwyb Form Builder features a visual drag-and-drop interface that makes it incredibly easy to build forms without writing a single line of code.
