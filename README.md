# 🛠️ Installation

## WordPress Admin

1. Open **Plugins → Add New**.
2. Search for **Dragwyb Forms**.
3. Click **Install Now**.
4. Click **Activate**.
5. Open **Dragwyb Forms**.
6. Create your first form.

## Manual Installation

1. Download the plugin ZIP.
2. Go to **Plugins → Add New → Upload Plugin**.
3. Upload the ZIP file.
4. Install and activate the plugin.
5. Open **Dragwyb Forms**.

# 🧑‍💻 Development

Clone the repository:

```bash
git clone https://github.com/Dragwyb/smart-form-builder-by-dragwyb.git
cd smart-form-builder-by-dragwyb
```

Install JavaScript dependencies:

```bash
npm install
```

Build production assets:

```bash
npm run build
```

For development:

```bash
npm run start
```

> Available npm scripts may vary depending on the current development branch.
